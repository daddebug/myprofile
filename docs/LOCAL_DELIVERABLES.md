# Local Deliverables

`local-deliverables/` is managed by DILIDA DESK as a submission-ready filesystem.

**LOCAL ONLY - NEVER PUBLISHED**

- Do not commit this directory.
- Do not collect it into publishing bundles.
- Do not expose any file in it through `publicPath`.
- Do not copy it into `public/`, `dist/`, or Vercel output.
- Each final delivery slot contains at most one current user-named file.
