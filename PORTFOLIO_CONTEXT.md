\# Portfolio Context



\## Positioning

This is a personal portfolio for game UX, interaction design, UI systems, and experimental game projects.



\## Main case studies

\- Cross-platform Game UX

\- Game Jam

\- 3D Character UI exploration

\- UI Personal Practice

\- Activity Design

\- Interaction Profile Agent



\## Visual direction

\- Personal archive rather than corporate consultancy

\- Geometric / Bauhaus influence

\- Sans-serif typography

\- Dark blue base with restrained bright green accents

\- Avoid generic gradients, oversized slogans, floating glass cards, and SaaS dashboard aesthetics



\## Editing system

\- Owner mode

\- User-created projects and blocks may be stored locally

\- Images and drafts must be preserved

\- Stable project IDs must not change



\## Important safety rules

\- Never clear localStorage

\- Never clear IndexedDB

\- Never delete image blobs

\- Never replace canonical data with defaults

\- Never publish or deploy without permission
